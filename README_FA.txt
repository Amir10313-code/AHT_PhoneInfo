AHT Phone Info  -  برنامه نمایش اطلاعات گوشی (اندروید)
سازنده: AHT TEAM
=====================================================

ویژگی‌ها
- حالت شب / حالت روز (با دکمه بالای صفحه؛ انتخاب شما ذخیره می‌شود)
- رابط کاملاً فارسی و راست‌چین
- ۱۵ بخش: خلاصه، دستگاه، سیستم‌عامل، پردازنده، کارت گرافیک، RAM، ذخیره‌سازی،
  نمایشگر، باتری، شبکه (با IP)، سیم‌کارت و اپراتور، دوربین‌ها، حسگرها،
  امکانات سخت‌افزاری، امنیت
- خروجی TXT (ذخیره در هر پوشه‌ای که انتخاب کنید) / کپی / اشتراک‌گذاری
- بدون هیچ مجوز خطرناکی؛ فقط دسترسی به وضعیت شبکه و Wi-Fi

ساخت فایل APK  (یکی از دو روش)
-----------------------------------------------------
روش ۱ - Android Studio (پیشنهادی)
  1. فایل zip را استخراج کنید.
  2. Android Studio را باز کنید: File > Open > پوشه پروژه.
  3. صبر کنید Gradle Sync تمام شود (بار اول نیاز به اینترنت دارد).
  4. منوی Build > Build Bundle(s) / APK(s) > Build APK(s)
  5. فایل APK اینجا ساخته می‌شود:
     app/build/outputs/apk/debug/app-debug.apk

روش ۲ - بدون نصب هیچ چیز (GitHub Actions)
  1. یک مخزن (Repository) در GitHub بسازید و محتوای این پوشه را آپلود کنید.
  2. تب Actions > Build APK > Run workflow
  3. پس از چند دقیقه، فایل APK را از بخش Artifacts دانلود کنید.

نصب روی گوشی
  فایل APK را به گوشی منتقل کنید و باز کنید. اگر پیغام امنیتی آمد،
  «نصب از منابع ناشناس» را برای همان برنامه (مرورگر یا مدیر فایل) فعال کنید.

نکات
- شناسه‌های هویتی مثل IMEI و شماره سریال عمداً نمایش داده نمی‌شوند
  (اندروید اجازه دسترسی به آن‌ها را به برنامه‌های عادی نمی‌دهد).
- نام Wi-Fi (SSID) هم بدون مجوز موقعیت مکانی در دسترس نیست.
